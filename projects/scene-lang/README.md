# scene-lang

Інтуїтивне відтворення «мови» відео @seaeees — піксель-арт сцена, що
**збирає сама себе** від скелета до фінального кадру, тими самими стадіями,
що й на відосі: `SKELETON → CLAY → COLOR → LIGHT → POST`.

Це перший прохід. Розшифровку підходу (stages + layers) див. у
[`SCENE-LANGUAGE.md`](./SCENE-LANGUAGE.md). Наступний крок — **layering & gridding**.

## Що всередині

- **`render.py`** — процедурний рендерер (numpy + статичний ffmpeg з `imageio-ffmpeg`).
  1-точкова перспективна кімната, впорядкований (Bayer) дизеринг, три плани
  глибини (FG/MG/BG), розмита летербокс-рамка як у джерелі.
- **`out/scene-build.mp4`** — фінальне відео (576×1026, 24 fps, ~9 с).
- **`stills/`** — по одному кадру на кожну стадію (`stage_1_skeleton` … `stage_5_post`).

## Запуск

```bash
pip install numpy imageio-ffmpeg      # див. requirements.txt
python render.py                      # відео + стадійні стіли
python render.py --stills             # лише стіли (швидко, для ітерацій)
DEBUG=1 python render.py --stills     # + мапа класифікації поверхонь
```

## Стадії

| Стадія   | Що додається                                            |
| -------- | ------------------------------------------------------- |
| SKELETON | точка сходу, перспективна сітка, вайрфрейм, рамка вікна  |
| CLAY     | сірі флети + ambient occlusion (значення, без кольору)  |
| COLOR    | палітра / альбедо (ще пласко)                           |
| LIGHT    | промінь від вікна, дизеринг, rim light, трава, персонаж |
| POST     | grade, зерно, віньєтка, DoF-летербокс                   |

## Що це відтворює з оригіналу

- покроковий «build» кадру (головна ідея відео — інструкція, а не таймлапс);
- дизерингова піксель-арт естетика @seaeees;
- поділ на плани FG / MG / BG + depth-of-field як інструмент розділення;
- вертикальна летербокс-рамка з розмитою копією сцени.
