# Frame Extractor

Окремий інструмент, що **розкладає відео на кадри** й зберігає їх як окремі
зображення. Живе всередині репозиторію `tt-cup`, але є самодостатнім
підпроєктом (власний скрипт, залежності, вихідні дані).

## Як працює

Використовує статичний бінарник `ffmpeg`, що постачається разом із пакетом
`imageio-ffmpeg`, тож **системний ffmpeg встановлювати не потрібно**.

## Встановлення

```bash
pip install -r requirements.txt
```

## Використання

```bash
# Усі кадри (повне розкладання) → ./output/<ім'я-відео>/
python extract_frames.py sample.mp4

# 1 кадр на секунду, у форматі PNG, у власну теку
python extract_frames.py sample.mp4 --fps 1 --format png --out frames/

# Кожен 5-й кадр, зменшений до 320px завширшки
python extract_frames.py sample.mp4 --every 5 --width 320
```

### Опції

| Опція        | Опис                                                           |
| ------------ | -------------------------------------------------------------- |
| `input`      | Шлях до відеофайлу (обов'язково).                              |
| `--out`      | Тека для кадрів (типово `./output/<ім'я-відео>/`).            |
| `--format`   | `jpg` (типово), `jpeg`, `png`, `bmp`, `webp`.                  |
| `--fps`      | Скільки кадрів на секунду брати (напр. `1`). Без цього — усі.  |
| `--every`    | Брати кожен N-й кадр (ігнорується, якщо задано `--fps`).       |
| `--width`    | Ширина вихідного зображення (px), пропорції зберігаються.      |
| `--height`   | Висота вихідного зображення (px), пропорції зберігаються.      |
| `--quality`  | Якість JPEG/WebP: 1 (найкраще) .. 31 (найгірше). Типово `2`.   |
| `--prefix`   | Префікс імен файлів (типово `frame`).                          |

Після кожного запуску поряд із кадрами створюється `manifest.json` із
метаданими (кількість кадрів, роздільність, fps, розмір тощо).

## Приклад (`sample.mp4`)

Демо-відео — вертикальний TikTok-кліп 576×1024, 30 fps, 12.07 с.

| Параметр       | Значення              |
| -------------- | --------------------- |
| Кадрів         | 362                   |
| Формат         | JPEG (`--quality 2`)  |
| Розмір на диску| ~18.4 MB              |
| Вихід          | `output/sample/`      |

Відтворити:

```bash
python extract_frames.py sample.mp4
```
